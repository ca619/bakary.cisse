# Exemple d’email suspect

## Objet
Action requise : activité inhabituelle détectée sur votre compte Microsoft 365

## Expéditeur
Microsoft Security Team <security-alert@micr0soft-verif.com>

## Destinataire
vous@entreprise.com

## Message

Bonjour,

Nous avons détecté une activité inhabituelle sur votre compte Microsoft 365 aujourd’hui à 03:14 AM depuis un appareil non reconnu.

Par mesure de sécurité, votre accès sera temporairement limité si vous ne confirmez pas votre identité dans les 30 minutes.

Veuillez vérifier vos informations immédiatement en cliquant sur le lien ci-dessous :

**Vérifier mon compte maintenant**  
http://microsoft-login-verification-secure.com/verify

Si vous ne confirmez pas votre compte, votre messagerie Outlook et vos fichiers OneDrive pourront être suspendus.

Merci de votre coopération,  
Microsoft Security Verification Center
