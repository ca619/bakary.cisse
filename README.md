### Détection d’un scan Nmap avec Suricata et Splunk

Lab SOC de détection d’une activité de reconnaissance réseau.  
Le projet simule un scan Nmap depuis Kali Linux vers un serveur Splunk, puis analyse les alertes générées par Suricata et visualisées dans Splunk.

**Compétences travaillées :**

- Scan réseau avec Nmap
- Détection IDS avec Suricata
- Analyse des logs `fast.log`
- Recherche d’événements dans Splunk
- Interprétation source / destination / ports
- Mapping MITRE ATT&CK : T1595 / T1046

➡️ [Voir le projet](./nmap-scan-detection-lab/README_projet_soc_suricata_splunk.md)
